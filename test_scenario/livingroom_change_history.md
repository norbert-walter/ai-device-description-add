# Living Room — Change History
(Companion document to livingroom_preferences.md)

This file records every content change to `livingroom_preferences.md`. Each entry must be created before or immediately after the corresponding change is made. Times are always recorded via a time tool, never estimated or invented.

---

## Entry Template

| Field | Value |
|-------|-------|
| **Entry ID** | CHG-XXXX |
| **Time of execution** | YYYY-MM-DD HH:MM:SS (Europe/Berlin) |
| **Initiated by** | [person name or "user"] |
| **Executed by AI model** | [model name and version] |
| **Approved by** | [person name] |
| **Time of approval** | YYYY-MM-DD HH:MM:SS (Europe/Berlin) |
| **Reason** | [what prompted the change] |
| **Type** | Addition / Correction / Restructuring / Deletion |
| **Section affected** | [chapter or table row] |
| **Change description** | [brief description of what was added, corrected, or removed] |
